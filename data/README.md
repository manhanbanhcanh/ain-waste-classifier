```text
data/
├── LICENSE.md      # TrashNet source, license, pinned commit, sha256
├── README.md       # this file
└── sample/         # <=20 tiny original synthetic images, offline smoke tests
    ├── cardboard/
    ├── glass/
    ├── metal/
    ├── paper/
    ├── plastic/
    └── trash/
```

After you (optionally) run `scripts/prepare_dataset.py --confirm`, three more
directories appear and are **git-ignored**:

```text
data/
├── train/
├── validation/
└── test/
```

## `data/sample/`

Six sub-folders, one per TrashNet class (`cardboard`, `glass`, `metal`, `paper`,
`plastic`, `trash`), each holding one or more tiny `.png` images. They are
**original synthetic images** generated by `scripts/make_sample_images.py`
(colored rectangles encoded directly with the standard-library `zlib`
module — no photos, no web scrapes, no PIL/Pillow dependency to generate
them). A couple of files are deliberately "hard" (blurred or darkened) so
you have at least one difficult/edge-case image per the required demos.

Use these for:

- building and unit-testing `starter/student_core.py` before downloading
  anything;
- the offline pytest sanity suite (`tests/test_project_11_sanity.py`);
- a quick manual Streamlit smoke test (`streamlit run starter/app.py`).

Do **not** try to train a real CNN to convergence on `data/sample/` alone —
eight tiny synthetic images cannot teach a network to see real trash. They
exist for infrastructure testing, not for the graded training run.

## `data/train/`, `data/validation/`, `data/test/` (optional, git-ignored)

Written only after you run:

```bash
python scripts/prepare_dataset.py --confirm
```

This downloads the single pinned TrashNet archive described in
`data/LICENSE.md`, verifies its sha256, and splits it 70/13/17 (train /
validation / test) per class with a fixed seed (`42`), matching the split
used in the original TrashNet paper. This step is **optional preflight**,
not the student zip gate: the midterm can be smoke-tested entirely on
`data/sample/` plus the script itself, and the zip you submit must not
contain `data/train/`, `data/validation/`, or `data/test/` (see
the course submission guidelines and the root `.gitignore`).

## Regenerating `data/sample/`

```bash
python scripts/make_sample_images.py
```

Deterministic (`--seed 42` by default): re-running it reproduces byte-identical
PNGs. You should not need to run this yourself unless you want extra local
"hard" images for the fourth required demo (local image outside the original
test set) — the repository already ships the images this script produces.
